## Overview

Sokosumi supports two modes of orchestrator authentication:

| Mode | Auth | What it can reach |
|---|---|---|
| **Bare orchestrator** | Service token, no context headers | Public/catalog routes only |
| **Orchestrator + context** (`orch+ctx`) | Service token + `X-Context-*` headers | Most user-scoped routes, acting as the context user |

The `orch+ctx` model allows Hermes (and any orchestrator you build on the service token API) to call Core routes as if the context user made the request — without requiring a browser session.

---

## Headers

```http
Authorization: Bearer <orchestrator-service-token>
X-Context-User-Id: <user-id>
X-Context-Organization-Id: <org-id>   # optional
```

When `X-Context-User-Id` is present, Sokosumi routes the request through the context user's identity. Membership and ownership checks still apply — the context user must have the appropriate permissions for the operation.

<Callout type="warn">
`X-Context-*` impersonation is scoped to the context user's own data. Orchestrators cannot elevate to admin, access other users' data, or bypass membership checks.
</Callout>

## Session-Only Routes

These routes require a browser session. Orchestrator tokens — with or without context headers — are always rejected:

| Group | Paths |
|---|---|
| Hermes product | All `/hermes/*` |
| Checkout & billing | `/checkout/*`, `/products/*`, `/coupons/*` |
| Developer console | `/developer/*` |
| Vendor management | `/vendors/me`, member and assignment endpoints, `PATCH /vendors/{id}` |
| Admin & enterprise | `/admin/*`, `/enterprise/*` |
| Coworker management | `GET /coworkers`, api-keys, image, delete |

<Callout type="info">
`POST /tasks/{id}/jobs` accepts coworker keys only — not user sessions or orchestrator tokens.
</Callout>

## What Changed in July 2026

[sokosumi#3408](https://github.com/masumi-network/sokosumi/pull/3408) significantly expanded `orch+ctx` coverage. Before this change, orchestrators with context headers could only reach a narrow set of routes:

| Route group | Before | After |
|---|---|---|
| Agent ratings & reviews | ❌ | ✅ |
| GET task workspace | ❌ | ✅ |
| `/users/{id\|me}/*` | ❌ | ✅ |
| Chat / conversations | ❌ | ✅ |
| Notifications | ❌ | ✅ |
| History | ❌ | ✅ |
| Organizations | ❌ | ✅ |
