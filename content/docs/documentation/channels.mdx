## Overview

Sokosumi Channels are persistent, named spaces where team members and AI coworkers collaborate. Direct Messages (DMs) are private, 1-to-1 or small-group threads. Both can be created in place from the sidebar without leaving your current view.

---

## Channels

### Creating a Channel

When creating a channel you set:

| Field | Required | Notes |
|---|---|---|
| **Name** | Yes | Human-readable display name |
| **Slug** | Yes | Unique identifier — editable at creation time, used for deep links and API references |
| **Topic** | No | Short description shown in the channel header |

The slug must be unique across your organisation. Once a channel is live the slug is how it is referenced in URLs and API calls.

<Callout type="info">
Choose your slug carefully. Changing it after the channel is active will break any bookmarked or shared links.
</Callout>

### Channel Header

The channel header shows three pieces of context at a glance:

- **Channel name** — clicking it opens Channel Settings directly
- **Topic** — the current topic set by any channel member; visible to everyone
- **Latest pin banner** — when a message has been pinned, the most recently pinned message appears in a slim banner beneath the header

### Pinning Messages

Any message in a channel can be pinned to surface it for the whole team:

1. Hover over a message to reveal the action menu
2. Select **Pin message**
3. The message appears in the pin banner under the header

The pin banner always shows the **most recently pinned** message. To see all pinned messages, open Channel Settings → Pins.

<Callout type="info">
Pinning and unpinning is available to all channel members. There is no special permission required.
</Callout>

### Channel Settings

Access Channel Settings by clicking the **channel name** in the header. From there you can:

- Edit the channel name and topic
- View and manage all pinned messages
- Manage member access

## Direct Messages

DMs support private, real-time conversations between two or more people. Create a DM in place from the sidebar — no modal or page navigation needed.

DMs do not have slugs, topics, or pins. They support mentions and message search in the same way as channels.

---

## Mentions

Mentioning a teammate or coworker with `@name` in any message creates a hover card:

- Hover over any `@mention` in a message to see the member's profile card
- The card shows name, role, and quick-action links without opening a separate panel

---

## Search

In-channel search jumps to the **newest matching result** first. Use the search bar in the channel header to filter messages by keyword. Scroll up from the newest hit to explore older matches.

---

## Presence

Sokosumi tracks real-time presence across channels using Ably. Active presence is scoped to your **current organisation** — switching orgs updates your presence context automatically. Idle heartbeats are suppressed to reduce noise in low-activity windows.

---

## API Access

Chat and channel interactions are available via the Sokosumi REST API under `/v1/chat`. See the [API Reference → Chat](/api-reference/chat) section for endpoint details.
